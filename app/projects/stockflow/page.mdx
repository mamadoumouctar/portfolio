# StockFlow

**Système de gestion de stock multi-points** · Projet personnel · Déployé en production · 2026

`Express` · `PostgreSQL` · `Docker` · `Authelia` · `Nginx Proxy Manager`

## Voir en ligne

- **Application** : [preview.stockflow.mouctar.dev](https://preview.stockflow.mouctar.dev)

## Aperçu

StockFlow est une application personnelle de **gestion de stock répartie sur plusieurs points** (points de vente ou emplacements). Elle couvre l'ensemble du cycle : catalogue de produits, niveaux de stock, transferts entre points, ventes et retours. L'interface web est pensée **mobile-first** (installable comme application web).

Au-delà des fonctionnalités, le projet est un terrain d'expérimentation **DevOps** complet : conteneurisation, hébergement sur VPS, reverse proxy et authentification centralisée.

## Fonctionnalités

- **Produits** : gestion du catalogue de produits.
- **Stock** : suivi des niveaux de stock par point.
- **Transferts** : déplacement de stock entre points.
- **Ventes** : enregistrement des ventes.
- **Retours** : traitement des retours.


## Architecture technique

- **API** : Express (Node.js), API REST, documentation via Swagger ui.
- **Base de données** : PostgreSQL.
- **Conteneurisation** : Docker (docker compose) pour l'ensemble des services.
- **Reverse proxy** : Nginx Proxy Manager (NPM) — routage, TLS/HTTPS.
- **Authentification & autorisation** : Authelia.

Cette approche centralise l'authentification (SSO) et l'autorisation en dehors du code applicatif : l'API n'a pas à gérer elle-même les sessions et les règles d'accès, ce qui renforce la sécurité et simplifie la maintenance.
