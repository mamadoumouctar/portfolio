## Architecture technique

- **Langage & build** : Java 21, Maven 3.x
- **API** : Jersey (services REST / appels HTTP)
- **Persistance configurable** : stockage **in-memory** ou **MongoDB**, sélectionné via la propriété `persistence` (`inmemory` / `mongo`)
- **Conteneurisation** : Docker (`docker compose up`)

Cette persistance interchangeable illustre une conception découplée : la logique métier ne dépend pas d'une base de données précise, ce qui facilite les tests et l'évolution.

## Démarche qualité & CI/CD

- **Intégration continue** via **GitHub Actions** : exécution automatique des tests à chaque contribution.
- **Quality gate SonarCloud** : analyse statique, suivi de la **couverture de code** et détection des bugs.
- **OWASP Dependency Check** : analyse automatique des vulnérabilités des dépendances.
- **Pratiques Agile** : sprints, revues de code et rétrospectives, dans une logique de **Clean Code**.
